  • Designed an evaluation harness (recall@5, precision@5, MRR) against a hand-labelled query set and benchmarked six retrieval variants, choosing the shipped approach on measured evidence rather than intuition.
  • Diagnosed two measurement failures that were understating true performance — an embedding-window bug and a capped recall denominator — and corrected them, raising measured MRR from 0.444 to 0.917 with no change to retrieval itself: a case study in not trusting a metric before auditing it.
  • Enforced hallucination and scope guardrails in code rather than relying on prompt instructions alone, backed by ~100 automated adversarial and over-refusal tests — a deliberate reliability-over-flexibility trade-off.
  • Cut end-to-end latency from 8.6s to 2.4–4.1s; after profiling showed 98.7% of remaining wait was unavoidable model-generation time, rejected response streaming as a fix because it would have weakened the citation guardrail.
  • Audited data-licensing terms, re-sourced the corpus when the original provider prohibited permanent caching, and verified character-identical integrity across all 6,236 verses before migrating.
